## 1. Master Windows & Linux Digital Forensics & Reversing Command Matrix

| Command Syntax (`Windows` / `Linux`) | OS / Tool | Operational Purpose & Key Flags | When to Apply & Expected Output | Companion Playbook |
| :--- | :--- | :--- | :--- | :--- |
| `reg save HKLM\SAM C:\Temp\SAM.hiv /y & reg save HKLM\SYSTEM C:\Temp\SYSTEM.hiv /y & esentutl /y C:\Windows\System32\sru\SRUDB.dat /d C:\Temp\SRUDB.dat /vss` | **Windows Native (`CMD`)** | Acquires locked Windows Registry hives (`SAM`, `SYSTEM`) and the 30-day System Resource Usage Monitor database (`SRUDB.dat`) via Volume Shadow Copy. | Apply during Windows live forensic triage before rebooting or isolating the host. | [[reasoning/windows_digital_forensics_strategy_playbook]] / [[commands/windows_digital_forensics_playbook]] |
| `hayabusa.exe csv-timeline -d "C:\Windows\System32\winevt\Logs" -o C:\Temp\hayabusa.csv --no-wizard` & `MFTECmd.exe -f "C:\Temp\$MFT" --csv C:\Temp\out --csvf mft.csv` | **Windows Open-Source (`Hayabusa` / `Zimmerman`)** | Generates a Sigma-enriched `.evtx` incident timeline (`hayabusa`) and parses raw NTFS `$MFT` records (`MFTECmd`). | Apply when reconstructing Windows attack timelines across Event Logs, `$MFT`, `$UsnJrnl`, Prefetch (`PECmd`), and `AmcacheParser`. | [[reasoning/windows_digital_forensics_strategy_playbook]] / [[commands/windows_digital_forensics_playbook]] |
| `vol -f physmem.raw windows.pstree && vol -f physmem.raw windows.malfind && vol -f physmem.raw windows.netscan` | **Cross-Platform (`Volatility 3` / `MemProcFS`)** | Analyzes Windows physical RAM dumps (`winpmem`) for unlinked processes, `PAGE_EXECUTE_READWRITE` injected code (`malfind`), and network sockets. | Apply when investigating memory dumps or running `hollows_hunter64.exe /hooks /shellc` on live Windows hosts. | [[reasoning/windows_digital_forensics_strategy_playbook]] |
| `ls -la /proc/[0-9]*/exe 2>/dev/null \| grep -E '\(deleted\)\|memfd:'` $\to$ `cp /proc/<PID>/exe /tmp/recovered_<PID>.elf && grep -H "rwxp" /proc/[0-9]*/maps` | **Linux Native (`Bash` / `/proc`)** | Recovers unlinked `(deleted)` or `memfd:` fileless ELF binaries directly from kernel RAM and identifies anonymous `rwxp` shellcode mappings. | Apply first during live Linux forensic triage before terminating suspicious processes. | [[reasoning/linux_digital_forensics_strategy_playbook]] / [[commands/linux_digital_forensics_playbook]] |
| `sudo ./avml --compress /tmp/linux_ram.lime && sudo ./uac -p ir_triage /tmp/uac_out && fls -r -m "/" /dev/sda1 > /tmp/bodyfile && mactime -b /tmp/bodyfile -d -z UTC > /tmp/macb.csv` | **Linux Open-Source (`AVML` / `UAC` / `SleuthKit`)** | Acquires Linux physical RAM without compiling a kernel module (`avml`), collects live IR artifacts (`uac`), and builds a full UTC MACB inode timeline (`fls` + `mactime`). | Apply during comprehensive Linux incident response and disk/memory forensics. | [[reasoning/linux_digital_forensics_strategy_playbook]] / [[commands/linux_digital_forensics_playbook]] |
| `reait -b "<BINARY>" -a && reait -b "<BINARY>" -M && reait -b "<BINARY>" -x` | **Cross-Platform (`RevEng.AI` CLI)** | Uploads `<BINARY>` to RevEng.AI (`-a`), auto-unstrips function symbols via BinNet similarity matching (`-M`), and extracts function embedding vectors (`-x`). | Apply when reverse engineering stripped PE/ELF/firmware binaries (`https://github.com/orgs/RevEngAI/repositories`). | [[reasoning/reverse_engineering_strategy_playbook]] / [[commands/revengai_and_binary_reversing_playbook]] |
