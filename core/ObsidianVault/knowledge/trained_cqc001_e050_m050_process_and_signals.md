## LLM Distilled Operational Summary
### Key Operational Techniques & Decision Workflows

*   **Process Lifecycle Management**: Monitor processes through five distinct states: `New` (descriptor allocated), `Ready` (mapped in memory), `Running` (CPU execution), `Waiting/Suspended` (I/O or event wait), and `Terminated`.
*   **Signal Handling Workflow**:
    1.  **Generation**: Trigger via system calls (e.g., `kill`) or hardware events.
    2.  **Delivery**: Determine disposition (Ignore, Default Action, or Custom Handler).
    3.  **Blocking**: Use signal masks to postpone delivery until the signal is pending.
*   **Thread Communication**: Leverage shared resources (code, data, libraries) in multithreaded models for efficient inter-thread communication, while managing private stacks and descriptors per thread.
*   **Core Dump Analysis**: Utilize core dumps generated by fatal signals (e.g., `SIGSEGV`, `SIGFPE`) to analyze memory access violations or arithmetic errors.

### Critical Command Patterns & Required Flags

*   **Signal Generation**:
    *   `kill [PID]`: Sends default signal (usually `SIGTERM`) to terminate a process.
    *   `kill -9 [PID]`: Sends `SIGKILL` (uncatchable, immediate termination).
    *   `kill -15 [PID]`: Sends `SIGTERM` (gentle kill allowing cleanup).
    *   `kill -SIGINT [PID]`: Simulates `Ctrl+C`.
    *   `kill -SIGSTOP [PID]`: Pauses process execution.
    *   `kill -SIGCONT [PID]`: Resumes a stopped process.
*   **Process Inspection**:
    *   Research `ps`, `top`, and `pgrep` to identify running processes and their states.
    *   Analyze ELF files (executables, libraries, core dumps) using tools like `readelf` or `objdump`.

### Network Topology & Service Relationships

*   **Process Table**: The UNIX kernel maintains a global table listing all active processes, serving as the central registry for scheduling and resource management.
*   **Inter-Process Communication (IPC)**: Implicitly relies on file descriptors managed within the process descriptor for resource sharing and signaling.
*   **Terminal Interaction**:
    *   `Ctrl+D` generates `SIGHUP` (Hangup/Disconnection).
    *   `Ctrl+C` generates `SIGINT` (Keyboard Interrupt).
    *   `Ctrl+\` generates `SIGQUIT` (Quit with core dump).
*   **Architecture Agnosticism**: The ELF format and signal mechanisms are portable across major UNIX variants (System V, Solaris, Linux, BSD), ensuring consistent behavior regardless of underlying hardware architecture.
